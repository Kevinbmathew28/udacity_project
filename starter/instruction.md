# GitHub Copilot Instructions

This project is a Flask Sudoku application.

Guidelines for GitHub Copilot:
- Use modern Python and Flask best practices.
- Keep the code modular and reusable.
- Preserve existing functionality while adding new features.
- Write or update pytest tests for new functionality.
- Keep HTML, CSS, and JavaScript responsive.
- Support light and dark mode.
- Explain significant code changes before applying them.
